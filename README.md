# Modularity on the Karate Club Graph

## Introduction

This project is part of the DSC212 Graph Theory module. In this assignment, I have studied community detection using the Karate Club graph.

The main aim of this project is to identify different communities in a network using the concept of **modularity**. I have used the spectral modularity method to divide the graph into smaller groups.

## Objectives

- To understand the concept of modularity.
- To construct the modularity matrix using the adjacency matrix.
- To implement recursive spectral community detection.
- To visualize the graph after each splitting stage.
- To calculate different network metrics for each node.
- To study how these metrics change when the network is divided into communities.

## Tools and Libraries Used

- Python
- NumPy
- NetworkX
- Matplotlib
- Pandas

## Network Metrics

The following metrics are calculated in this project:

1. Degree Centrality
2. Betweenness Centrality
3. Closeness Centrality
4. Clustering Coefficient

## Files

- `DSC212_Karate_Club_Modularity_Assignment.ipynb` – Jupyter notebook containing the implementation, visualizations and discussion.

## Conclusion

Through this assignment, I learned how modularity can be used to identify communities in a network. I also studied how the centrality measures of nodes change when the network is divided into smaller communities.
